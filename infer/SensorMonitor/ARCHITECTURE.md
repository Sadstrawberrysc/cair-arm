# SensorMonitor

KWR57 基础工具：直连采集 → 稳定窗口软件清零 → 实时显示 / CSV 保存 → 均值 ± 标准差图片。
不再包含 Redis、Haptron、机器人状态与补偿曲线、漂移拟合、多格式报告和小时文件轮转。

- [main.py](main.py)：串口采集线程及实时六轴曲线，支持无界面运行。
- [kwr57.py](kwr57.py)：28 字节 RS422 帧解析，kgf/kgf·m 乘 9.80665 转 N/N·m。
- [zeroing.py](zeroing.py)：连续稳定 3 秒后求六轴固定零偏；支持手动重新清零。
- [recording.py](recording.py)：采集线程写一个 CSV，保存原始值与清零后值，每秒刷新缓冲。
- [analyze.py](analyze.py)：流式统计每秒六轴均值与样本标准差，生成一张 PNG。
- [record.py](record.py)：无界面采集入口，Ctrl+C 后保存并出图。

默认 `/dev/ttyUSB0`、460800 baud、8N1。独占串口，发送 `48 AA 0D 0A` 启流，退出尝试
`43 AA 0D 0A` 停流。解析帧头 `48/49 AA`、六个小端 float32 和 CRLF 帧尾；丢弃噪声、
错误帧尾与非有限数值，协议无 CRC。超过 1 秒无有效帧或串口/写盘错误时停止，不自动重连。

所有有效帧先写盘，再限频到最多 50 Hz 放入有界显示队列；GUI 每 100 ms 重绘最近 20 秒。
记录使用主机接收时间，同批帧时间相同，不代表设备采样时刻。停止时等待采集线程关闭 CSV。
写盘同步执行，不保证设备无丢帧；没有额外日志、元数据或后台落盘队列。

清零时需保持装配姿态固定且无外部接触。3 秒窗口内六轴样本标准差上限为
`[0.5 N × 3, 0.01 N·m × 3]`，前后半窗均值差上限为 `[0.1 N × 3, 0.005 N·m × 3]`。
零偏确定后固定减去，不自动抵消后续载荷或漂移；重新清零生成新的 `zero_id`，图片分段绘制。
清零完成前只保留原始值，不参与清零后的统计。

使用命令、CSV 和图片含义见[使用说明](../../docs/sensor_drift_recording.md)。
